# Advanced Learners Activities – Practical Write-up

## Activity 1: Create and maintain a GitHub repository for Java OOP practical assignments
**Aim:** To create and maintain a GitHub repository containing Java OOP practical assignments.
**Procedure:** Create a repository, initialize Git in the local folder, add source files, commit changes, connect the remote repository and push to GitHub.
**Learning outcome:** Develop independent programming and version-control skills.

## Activity 2: Develop a Java mini-project using inheritance, polymorphism, abstraction and interfaces
**Aim:** To apply advanced OOP principles in a Java application.
**Project:** Inventory Management System.
**Concepts:** Abstract User class, Admin inheritance, overridden dashboard method, Manageable interface, encapsulated Product class.
**Learning outcome:** Apply advanced OOP principles in application development.

## Activity 3: Collaborate with peers using branches, commits and pull requests
**Aim:** To collaborate with peers on a Java project using GitHub.
**Procedure:** Invite a collaborator, clone the repository, create a feature branch, commit and push changes, create a pull request, review and merge it.
**Learning outcome:** Develop teamwork and collaborative software-development skills.

## Activity 4: Develop a Java application using exception handling, multithreading and collections
**Aim:** To use advanced Java programming features.
**Implementation:** Custom exception validates stock quantity, ArrayList stores product names, and separate threads generate sample reports.
**Learning outcome:** Enhance advanced Java programming skills.

## Activity 5: Review peers' Java code and suggest improvements through GitHub pull requests
**Aim:** To review source code and provide constructive improvements.
**Procedure:** Inspect a peer's pull request, review naming, validation, exception handling and documentation, leave comments and submit a review.
**Learning outcome:** Improve code-review and analytical skills.

## Activity 6: Develop a Library Management System using OOP concepts
**Aim:** To develop and document a Java application using OOP.
**Features:** Add, view, issue and return books.
**Concepts:** Encapsulation, abstraction, inheritance, polymorphism and collections.
**Learning outcome:** Develop software-design, implementation and documentation skills.

## Conclusion
The six activities provide practical experience in Java OOP, advanced Java features, Git/GitHub version control, collaboration, code review, software development and documentation.
