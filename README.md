# Java OOP – Advanced Learners Activities

This repository contains Java source code and documentation for the six Advanced Learners Activities.

## Contents
1. `Activity-1-Java-OOP-Programs` – ten standalone Java OOP practice programs.
2. `Activity-2-Inventory-Management` – console-based inventory mini-project demonstrating abstraction, inheritance, polymorphism, interfaces, and encapsulation.
3. `Activity-3-GitHub-Collaboration` – step-by-step branch, commit, push, pull-request and merge guide.
4. `Activity-4-Advanced-Java` – exception handling, collections and multithreading.
5. `Activity-5-Code-Review` – sample review, improvement checklist and pull-request template.
6. `Activity-6-Library-Management` – Java library mini-project using OOP and collections.

## Requirements
- JDK 17 or later (JDK 8+ should also work for most examples)
- Git and a GitHub account
- VS Code or another Java IDE

## Compile and run
Open a terminal in the folder containing a `.java` file. For a single-file program:
```bash
javac FileName.java
java FileName
```
For a project with multiple files in one folder:
```bash
javac *.java
java Main
```

## Note
These are educational sample projects. The Inventory and Library projects use in-memory collections, so data resets when the program exits. They do not claim to connect to MySQL. You can add database persistence as a separate extension.
